Finalmente chegamos na parte da implementação segura vamos então agora a partir da arquitetura ao código na aula anterior nós tivemos algumas reflexões sobre como construir uma arquitetura segura agora nós vamos partir para o próximo passo o mais importante aqui é que nós consigamos perceber que a arquitetura ela não se implementa sozinho é por isso que na implementação segura nós precisamos transformar as decisões arquiteturais em código na aula anterior nós projetamos uma arquitetura segura para o sistema de matrículas identificamos componentes limites de confiança e pontos de entrada onde podem também ser chamados de superfícies de ataques também tomamos decisões como autenticar cada usuário verificar permissões no servidor aplicar o menor privilégio proteger operações críticas registrar as ações relevantes e aí preservar a disponibilidade do sistema.
